# Спецификация: «Кто выгуливает Бориса»

## Назначение

Самостоятельное одностраничное Node.js-приложение для демонстрации общего расписания прогулок с псом Борисом. На странице отображаются дата и пять фиксированных временных слотов. Посетитель может отметить время, сбросить выбор и проверить время сервера. Это только локальное подтверждение, реальное бронирование не выполняется.

## Состав и визуальное направление

- Одна страница `index.html` с весёлым зелёным фоном, жёлтым главным экраном, коралловыми акцентами и крупной типографикой.
- Шапка, первый экран с текущей московской датой, иллюстрация Бориса, ровно пять слотов прогулки, карточка «Пёс Борис», три коротких шага.
- Кнопки выбора времени и сброса, а также проверка времени сервера с видимыми сообщениями о результате.

## Технические границы

- Структура корня: `AGENTS.md`, `README.md`, `PLAN.md`, `spec.md`, `index.html`, `package.json`, `server.js`, `amvera.yaml`. `index.html` остаётся клиентским интерфейсом; Node.js-сервер отдаёт его по HTTP.
- `server.js` использует только встроенные `node:http`, `node:fs` и `node:path`; слушает `0.0.0.0`, порт `process.env.PORT` или 3000.
- `GET /` и `GET /index.html` отдают существующую страницу; неизвестные маршруты получают HTTP 404.
- `GET /api/menu` возвращает JSON с пятью фиксированными слотами прогулки на сегодня: 10:00, 12:00, 14:00, 16:00 и 18:00.
- `POST /api/selection` принимает JSON с ID слота, проверяет его и возвращает локальное подтверждение без сохранения.
- `POST /api/reset` возвращает подтверждение сброса выбора; `GET /api/status` возвращает JSON с `ok: true` и текущим серверным временем.
- Выбор не записывается в файлы, базу данных, SQLite, браузерное хранилище или изменяемое состояние сервера. Нет серверных данных о заказах.
- Только встроенные модули Node.js; `package.json` имеет `"private": true`, не содержит зависимостей, `start` запускает `node server.js`, `build` проверяет `server.js` командой `node --check`.
- Без фреймворков, пакетных зависимостей, базы данных, SQLite, Docker, Volume, Variables, Amvera CLI, отдельных статических папок, внешних шрифтов/изображений/скриптов/стилей, сетевых запросов, оплаты, настоящих бронирований, авторизации, хранения в браузере, реальных персональных данных и секретов.
- Не добавлять функции вне описанного демо-сценария.

## Наблюдаемая проверка

Запустить `npm run build` и `npm start`, открыть `http://localhost:3000`, проверить дату и пять слотов прогулки, выбрать время, сбросить его, запросить серверное время и убедиться, что неизвестный URL возвращает 404. В сетевой вкладке проверить ответы четырёх API-маршрутов. Перезагрузка страницы возвращает демо в исходное состояние: записи не сохраняются. Проверить деплой на Amvera по манифесту.
