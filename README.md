# Кто выгуливает Бориса

Общее приложение вымышленной московской компании «Догяндекс» (111 сотрудников), чтобы записаться на прогулку с офисным псом Борисом и видеть, кто гуляет сегодня. На общей странице нет регистрации или авторизации. Дополнительно на ней показана карточка последнего кормления.

## Локальный запуск

После реализации установите поддерживаемую проектом версию Node.js, из корня проекта выполните `npm install`, затем `npm run dev` и откройте адрес, напечатанный приложением (по умолчанию `http://localhost:3000`). Сервер и файл SQLite должны оставаться запущенными/доступными, пока вы проверяете сохранение записей. Для проверки общего состояния откройте тот же адрес в другом браузере.

Приложение предназначено для локального запуска и демонстрации; оно не подключается к реальным сервисам и не использует настоящие персональные данные.

## Документы и готовность

- `spec.md` — сценарий, границы и наблюдаемые критерии приёмки.
- `AGENTS.md` — правила работы с проектом.
- `PLAN.md` — четыре небольших шага реализации.

Завершайте работу при выполнении семи критериев DoD из `spec.md`; дополнительная полировка сверх них не входит в объём.
