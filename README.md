# Кто выгуливает Бориса

Одностраничное приложение с общим расписанием прогулок. На сегодня по московскому времени доступны пять слотов: 10:00, 12:00, 14:00, 16:00 и 18:00. Чтобы занять свободный слот, укажите ФИО. Занятость и имя сразу становятся видны всем посетителям; повторная запись в занятый слот отклоняется сервером.

## Локальный запуск

Требуется Node.js 22.5 или новее. Используется встроенный `node:sqlite`; устанавливать пакеты не нужно.

```sh
npm start
```

Откройте <http://localhost:3000>. Проверка синтаксиса сервера:

```sh
npm run build
```

Доступные маршруты:

- `GET /` и `GET /index.html` — страница.
- `GET /api/menu` — дата по Москве и состояние пяти слотов.
- `POST /api/selection` — запись `{ "id": "10:00", "fullName": "Тестовый Сотрудник" }`; повторная запись возвращает `409 Conflict`.

SQLite хранит записи в `data/dogboris.sqlite`. Можно задать другой путь переменной `DATABASE_PATH`. Файл базы данных не должен очищаться между запусками, если требуется сохранить расписание.

## Деплой на Amvera

Загрузите файлы проекта в приложение Amvera и используйте корневой `amvera.yaml`: окружение Node.js, toolchain npm 22, сборка `npm run build`, запуск `npm run start`, порт контейнера 3000. Сервер слушает `0.0.0.0` и использует порт из `PORT`, если платформа его задаёт. Для сохранения записей при пересоздании контейнера направьте `DATABASE_PATH` на доступный для записи постоянный диск.

## Ограничения

Расписание фиксировано и относится только к текущей московской дате. Нет регистрации, авторизации, редактирования или отмены записей, внесения кормления, внешних сервисов и реальных тестовых ФИО. Карточка последнего кормления — статичная демонстрационная информация.

В исходных файлах не было локальной фотографии Бориса, поэтому сохранена встроенная SVG-иллюстрация; внешнее изображение не подключалось. Для буквального соответствия пункту о фотографии потребуется предоставить локальный файл.
