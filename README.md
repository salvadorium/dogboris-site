# Кто выгуливает Бориса

Одностраничное Node.js-приложение для демонстрации общего расписания прогулок с псом Борисом. Страница показывает пять фиксированных времён, позволяет отметить слот и сбросить выбор. Это демо: запись не бронируется и нигде не сохраняется.

## Локальный запуск

Требуется Node.js 18 или новее. Внешние пакеты устанавливать не нужно.

```sh
npm start
```

Откройте <http://localhost:3000>. Проверка синтаксиса сервера:

```sh
npm run build
```

## Деплой на Amvera

Загрузите файлы проекта в приложение Amvera и используйте корневой `amvera.yaml`: окружение Node.js, toolchain npm 18, сборка `npm run build`, запуск `npm run start`, порт контейнера 3000. Сервер слушает `0.0.0.0` и использует порт из `PORT`, если платформа его задаёт. Дополнительные зависимости и внешние сервисы не нужны.

## Границы демо

Вся страница, CSS и JavaScript находятся в `index.html`. Сервер использует только встроенные модули Node.js и отдаёт этот файл по `/`. API возвращает фиксированные слоты и локальные подтверждения, но не создаёт настоящих записей. Нет авторизации, оплаты, внешних запросов, баз данных, хранения в браузере или использования реальных персональных данных и секретов.
