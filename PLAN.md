# План

1. **Интерфейс и меню:** открыть страницу через Node.js и вручную проверить загрузку пяти слотов прогулок и карточки «Пёс Борис».
2. **Выбор:** отметить время прогулки, проверить подтверждение и выделение выбранной карточки; убедиться, что сервер не сохраняет выбор.
3. **Сброс и статус:** сбросить выбор в исходное состояние, проверить кнопку «Проверить время» и ответ `GET /api/status`.
4. **Финальная проверка и деплой:** выполнить `npm run build`, проверить `GET /`, `GET /index.html`, все API-маршруты и 404, затем проверить сборку и запуск на Amvera по `amvera.yaml`.
