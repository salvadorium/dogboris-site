# План проверки

1. **Запуск и дата:** выполнить `npm run build`, запустить `npm start`, открыть `http://localhost:3000` и проверить московскую дату и ровно пять слотов расписания.
2. **Свободный слот:** отправить синтетическое ФИО для свободного времени; проверить подтверждение и занятое состояние карточки с этим именем.
3. **Защита от повтора:** выполнить два последовательных запроса `POST /api/selection` на один слот. Первый должен вернуть `201`, второй — `409` с сообщением о занятом времени.
4. **Общее сохранённое состояние:** обновить страницу и открыть её во втором браузере; запись и ФИО должны совпадать. Перезапустить сервер и убедиться, что SQLite сохранила запись.
5. **Дополнительные состояния страницы:** проверить карточку последнего кормления с синтетическим ФИО без интерактива и три шага выбора.
6. **Материалы приёмки:** подготовить семь скриншотов существенных состояний, карточку кейса, демонстрацию и след одной итерации с ИИ; после выполнения семи критериев DoD остановить полировку.
