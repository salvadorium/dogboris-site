# Демонстрация

## Запуск

Требуется Node.js 22.5+. В корне проекта выполните:

```sh
npm start
```

Откройте <http://localhost:3000>. Для чистого локального набора можно задать отдельный путь `DATABASE_PATH`; записи в SQLite сохраняются между запусками, пока файл базы не удалён.

## Сценарий показа

1. Покажите дату по Москве и пять фиксированных карточек времени.
2. В свободной карточке введите вымышленное ФИО, например «Демо Сотрудник», и нажмите «Записаться».
3. Покажите подтверждение, занятый статус и ФИО; у занятой карточки больше нет кнопки записи.
4. Обновите страницу или откройте `http://localhost:3000` в другом браузере. Имя и занятость должны совпасть.
5. Покажите статичную карточку последнего кормления и три коротких шага.

## Проверка конфликта через curl

Сначала проверьте `GET /api/menu` и выберите свободный `id`. Запустите две команды подряд, подставив этот же ID и синтетическое ФИО: первая вернёт `201`, вторая — `409 Conflict` с сообщением о занятом слоте.

```sh
# В обоих запросах замените 18:00 на свободный id из меню, если он уже занят.
curl -i -X POST http://localhost:3000/api/selection -H "Content-Type: application/json" -d "{\"id\":\"18:00\",\"fullName\":\"Тестовый Сотрудник\"}"
curl -i -X POST http://localhost:3000/api/selection -H "Content-Type: application/json" -d "{\"id\":\"18:00\",\"fullName\":\"Тестовый Сотрудник\"}"
```
