# Правила работы

- Перед началом каждой задачи сначала прочитать `README.md`, `spec.md` и `PLAN.md`.
- Менять только согласованный скоуп и соблюдать технические границы из `spec.md`; не добавлять функции вне описанного сценария.
- После каждой задачи предложить наблюдаемую проверку, по которой можно подтвердить результат в браузере или локальным запуском.
- Не использовать реальные персональные данные, секреты, внешние сервисы или сетевые запросы.
